================================================================================
                  TIMETABLE GENERATOR - DATA REQUIREMENTS
                      Client Onboarding Data Sheet
================================================================================

This document outlines ALL data that must be loaded into the ERP system
BEFORE the timetable generator can function. These are PRE-REQUISITE DATA
items - not configurable settings that can be adjusted in the UI.

Note: Constraints (hard/soft), teacher availability, and solver preferences
are configurable via the timetable frontend and are NOT covered here.

┌─────────────────────────────────────────────────────────────────────────────┐
│  ✓ CAPACITY CHECKS                                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  FORMULA:                                                                   │
│  Total Periods Required = Σ(periods_per_week × number_of_sections)         │
│                           for each subject                                  │
│                                                                             │
│  Total Teacher Capacity = Σ(max_periods_week) for all teachers             │
│                                                                             │
│  REQUIREMENT: Capacity Ratio ≥ 1.2 (20% buffer minimum)                    │
│                                                                             │
│  Example Calculation:                                                       │
│  - 12 class sections × 40 periods/week = 480 periods required              │
│  - 15 teachers × 35 max periods = 525 capacity                             │
│  - Ratio = 525/480 = 1.09 ⚠️  TOO TIGHT! Need more teachers or reduce load │
│                                                                             │
│  □ Capacity ratio is at least 1.2                                          │
│  □ No individual teacher is overloaded                                     │
│  □ Specialist subjects have enough teachers for all sections               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  ✓ PERIOD COUNT CHECKS                                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  For each class section:                                                    │
│  Total min_per_week (all subjects) ≤ Periods available per week            │
│                                                                             │
│  Example:                                                                   │
│  - School has 8 periods/day × 5 days = 40 periods/week                     │
│  - Section 10A subjects: MATH(6) + ENG(6) + SCI(5) + SST(4) + HINDI(4)    │
│    + PE(2) + ART(2) + MUSIC(1) + PHY_LAB(2) = 32 periods                  │
│  - 32 ≤ 40 ✓ OK (8 free periods available for assembly/library/etc.)       │
│                                                                             │
│  □ No section has more required periods than available slots               │
│  □ Each section has reasonable buffer for free periods (5-15%)             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

================================================================================
                           COMMON MISTAKES TO AVOID
================================================================================

1. ❌ Teacher assigned subject they can't teach
   ✓ Ensure subjects_can_teach includes the subject

2. ❌ Missing class-subject-teacher mapping
   ✓ Every class must have ALL subjects mapped

3. ❌ Teacher overloaded (assigned more periods than max_periods_week)
   ✓ Calculate total periods per teacher before importing

4. ❌ Subject requires lab but no resource defined
   ✓ Define resource in Sheet 5 and link via resource_type

5. ❌ Inconsistent IDs across sheets
   ✓ Use exact same IDs (case-sensitive) in all references

6. ❌ Total subject periods > available periods per week
   ✓ Sum of min_per_week for all subjects must be ≤ periods/week
