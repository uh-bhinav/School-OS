
## **Your Role**

You are a senior software engineer tasked with debugging and fixing critical issues in a **school timetable generation system** built with **Google OR-Tools CP-SAT solver**. This system automatically creates weekly schedules for Indian schools (CBSE/ICSE/State Board) while satisfying complex constraints.

---

## **System Overview**

### **What the System Does**
The timetable generator takes school data (classes, teachers, subjects, constraints) and produces conflict-free weekly schedules where:
- Every class has subjects assigned to all periods
- Teachers are not double-booked
- Lab resources are shared appropriately
- Educational best practices are followed (core subjects in morning, balanced workload, etc.)

### **Technology Stack**
- **Backend**: Python, FastAPI, Google OR-Tools CP-SAT solver
- **Frontend**: React, TypeScript, TanStack Query
- **Database**: Supabase (PostgreSQL)
- **Architecture**: Constraint Programming solver that treats timetabling as a Constraint Satisfaction Problem (CSP)

## **Critical Bugs Requiring Your Attention**

### **BUG #1: Free Periods Appearing in Generated Timetables (CRITICAL)**
**Symptom:** Generated timetables contain slots marked as "Free Period" where no subject is assigned.

**What's Wrong:** This violates a fundamental hard constraint - **every academic period for every class must have exactly one subject assigned**. Free periods are absolutely not allowed in Indian school timetables.

**What You Need to Investigate:**
- Is there a constraint explicitly enforcing that all periods must be filled?
- Are subject frequency requirements adding up to the total available periods?
- Is teacher capacity sufficient to cover all required periods?
- Is the solver terminating with a complete solution or an incomplete one?

### **BUG #2: Language Tier Display is Incorrect (HIGH PRIORITY)**
**Symptom:** When a class has multiple language options for a tier (e.g., students can choose between Kannada OR Sanskrit for "First Language"), the timetable incorrectly shows just one language name (e.g., "Hindi") instead of showing the tier name with all options (e.g., "FIRST LANGUAGE (Kannada/Sanskrit)").

**What's Wrong:** The system fails to recognize when multiple teachers are teaching different language options simultaneously in the same period (language block), and displays it as if only one language is being taught.

**What You Need to Investigate:**
- Is the solution being enriched with language block metadata during postprocessing?
- Is the frontend checking for multiple-option scenarios before rendering?

## **Understanding the Indian School Language System (CRITICAL CONTEXT)**

### **The Three-Language Formula**

Indian schools typically follow a **configurable multi-tier language structure**:

1. **First Language (L1)**: Regional/mother tongue
2. **Second Language (L2)**: Usually English (often mandatory)
3. **Third Language (L3)**: Additional language

**Important:** The number of tiers is **school-configurable**. Some schools may have only 2 tiers, others may have 3 or more.

---

### **Two Distinct Scenarios**

#### **SCENARIO A: Single Option Per Tier (Typical for Lower Grades 1-7)**

**Example: Grade 6A**
```
Each tier has exactly ONE language assigned:
├─ First Language: Kannada (Teacher T012) - all students learn this
├─ Second Language: English (Teacher T004) - all students learn this
└─ Third Language: Hindi (Teacher T011) - all students learn this
```

**Characteristics:**
- **No student choice** - everyone learns the same languages
- **One teacher per language** assigned to the class
- **No language block synchronization** needed
- Scheduling works like any regular subject

**How Timetable Should Display:**
```
Period 2: Kannada (Teacher: Kavita Menon)
Period 4: English (Teacher: Anita Desai)
Period 6: Hindi (Teacher: Arun Kumar)
```

✅ **Display Rule:** Show the **individual language name**, not the tier name, because there's only one option.

---

#### **SCENARIO B: Multiple Options Per Tier (Typical for Higher Grades 8-10)**

**Example: Grade 8A**
```
First Language has MULTIPLE options (students choose one):
├─ Option 1: Kannada (Teacher T012) - some students choose this
└─ Option 2: Sanskrit (Teacher T013) - other students choose this

Second Language has ONE option:
└─ English (Teacher T004) - mandatory for all

Third Language has MULTIPLE options (students choose one):
├─ Option 1: Kannada (Teacher T012) - some students choose this
└─ Option 2: Hindi (Teacher T011) - other students choose this
```

**Characteristics:**
- **Student choice exists** - each student selects their preferred language
- **Multiple teachers assigned** to the same class for the same tier
- **Language block synchronization required** (see next section)
- Teachers teach **simultaneously** in the same period to different student groups

**How Timetable Should Display:**
```
Period 2: FIRST LANGUAGE (Kannada/Sanskrit)
          Teachers: Kavita Menon | Deepak Verma

Period 4: English (Teacher: Anita Desai)

Period 6: THIRD LANGUAGE (Kannada/Hindi)
          Teachers: Kavita Menon | Arun Kumar
```

✅ **Display Rule:** Show the **tier name with all options** when multiple options exist, along with all teachers.

---

### **The Language Block Synchronization Concept (CRITICAL)**

#### **What is a Language Block?**

A **language block** occurs when multiple teachers must teach different language options **simultaneously** in the same time slot because students have split into groups based on their language choice.

**Physical Reality:**
```
Monday Period 2 - "FIRST LANGUAGE" slot for Grade 8A:

├─ Classroom 1: Teacher T012 teaches Kannada to Group A students (who chose Kannada)
└─ Classroom 2: Teacher T013 teaches Sanskrit to Group B students (who chose Sanskrit)

Both teachers teaching at the SAME TIME in the SAME PERIOD.
```

**Why This Matters for the Solver:**

When scheduling a "FIRST LANGUAGE" period for Grade 8A, the constraint programming model must ensure:
1. **Teacher T012 (Kannada) is available** in that time slot
2. **Teacher T013 (Sanskrit) is available** in that time slot
3. **Both teachers are assigned to Grade 8A simultaneously**

This is a **HARD CONSTRAINT** - the solver must fail if this cannot be satisfied.

---

#### **Language Block Synchronization Rules**

**Rule 1: All Teachers in a Block Must Be Free Simultaneously**
```
If Grade 8A has a "First Language" period at Monday Period 2:
├─ Teacher T012 must not be teaching any other class at Monday Period 2
├─ Teacher T013 must not be teaching any other class at Monday Period 2
└─ Both are assigned to Grade 8A at Monday Period 2
```

**Rule 2: Language Blocks Only Apply When Multiple Options Exist**
```
Grade 6A (single option):
└─ Kannada period → Only Teacher T012 scheduled → NO language block

Grade 8A (multiple options):
└─ First Language period → Teachers T012 AND T013 scheduled → LANGUAGE BLOCK
```

**Rule 3: Each Tier is Scheduled Independently**
```
First Language (L1) period:  Monday Period 2
Second Language (L2) period: Wednesday Period 4
Third Language (L3) period:  Friday Period 6

These are DIFFERENT time slots - not simultaneous with each other.
Only the options WITHIN each tier are simultaneous.
```

---

### **Language Teacher Assignment Rules**

#### **Rule 1: Language Teachers Only Teach Languages**
```
✅ ALLOWED:
Teacher T012 (Kannada teacher) teaches:
├─ First Language Kannada
└─ Third Language Kannada

❌ NOT ALLOWED:
Teacher T012 teaches Mathematics, Science, or any non-language subject
```

---

#### **Rule 2: Same Teacher Can Teach Different Tiers to Different Classes**
```
✅ ALLOWED:
Teacher T012 can teach:
├─ First Language Kannada to Class 8A (during 8A's L1 period)
└─ Third Language Kannada to Class 9B (during 9B's L3 period - different time)
```

---

#### **Rule 3: Same Teacher Cannot Teach Multiple Tiers to the Same Class**
```
❌ NOT ALLOWED:
Teacher T012 teaching:
├─ First Language Kannada to Class 8A
└─ Third Language Kannada to Class 8A

Reason: Students cannot learn the same language in two different tiers.
If a student chose Kannada as First Language, they cannot choose Kannada as Third Language.
```

**Note:** This rule should be enforced during **input data validation** before the solver runs. If the subject-teacher-class mapping contains such a scenario, reject the input as invalid.

---

**Example Data:**

**Key Logic:**

## **The "No Free Periods" Hard Constraint**

### **The Rule**

**Every academic period for every class must have exactly one subject assigned.**

**Formal Definition:**
```
For each class C:
  For each day D (Monday to Saturday):
    For each period P (excluding prayer/recess/lunch):
      There must exist exactly ONE pair (Subject S, Teacher T) assigned to (C, D, P)
```

**What This Means:**
- If a class has 48 academic periods per week, **all 48 must be filled** with subjects
- Zero "Free Period" slots are permissible
- If the solver cannot fill all periods, it should return **INFEASIBLE** (not a partial solution)

---

### **Why Free Periods Are Appearing (Potential Root Causes)**

#### **Possibility 1: Missing Hard Constraint**
The solver may not have an explicit constraint enforcing that all periods must be filled. Without this, the solver might find a "valid" solution that leaves some periods empty.

#### **Possibility 2: Subject Frequency Mismatch**
```
Example Problem:
├─ Total available periods per week: 48
├─ Sum of min_weekly_periods for all subjects: 40
└─ Gap: 8 periods unaccounted for → solver leaves them as free periods
```

The sum of minimum weekly periods across all subjects must **exactly equal** the total available academic periods.

#### **Possibility 3: Insufficient Teacher Capacity**
```
Example Problem:
├─ Total periods required: 480 (48 periods × 10 classes)
├─ Total teacher capacity: 450 (sum of all max_periods_week)
└─ Shortfall: 30 periods cannot be assigned
```

If total teacher capacity is less than total required periods, some periods will remain unfilled.

#### **Possibility 4: Solver Terminating Early**
The solver might be hitting a time limit and returning a **FEASIBLE** (but incomplete) solution instead of continuing to find an **OPTIMAL** solution where all periods are filled.
